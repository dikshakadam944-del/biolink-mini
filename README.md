# BioLink Mini 🚀

> **Your Entire Online Presence. One Simple Link.**

BioLink Mini is a modern, responsive, and lightweight link-in-bio website builder designed for content creators, freelancers, influencers, students, and small businesses. Create an elegant one-page personal website showcasing your social media links, portfolio, contact details, and custom scannable QR code.

![BioLink Mini Preview](https://images.unsplash.com/photo-1618005182384-a83a8bd57fbe?auto=format&fit=crop&w=1200&q=80)

---

## ✨ Features

- **📱 Interactive Live Preview Studio:** Dynamic in-browser sandbox to test real-time bio/name changes, switch between creator personas, and toggle color themes.
- **🎨 4 Beautiful Curated Themes:** *Purple Glow*, *Ocean Deep*, *Emerald Nature*, and *Sunset Minimal*.
- **🔗 Multi-Platform Social Connectivity:** Pre-styled links for Instagram, LinkedIn, YouTube, WhatsApp, GitHub, and custom portfolio links.
- **📷 Custom Scannable QR Code:** Automatically generates crisp vector QR codes ready for business cards, resumes, or event flyers.
- **💬 Direct WhatsApp & Contact Routing:** 1-tap messaging and inquiry form modal.
- **⚡ Blazing Fast & Lightweight:** Zero build steps required; powered by pure HTML5, vanilla JavaScript, and modern CSS with Tailwind CSS.
- **💎 Fully Responsive:** 100% mobile-first design with smooth animations and touch-friendly controls.

## 🚀 Quick Start

1. Clone this repository:
   ```bash
   git clone https://github.com/dikshakadam944-del/biolink-mini.git
   cd biolink-mini
   ```
2. Open `index.html` in any modern web browser:
   - On Windows: Double-click `index.html` or run `start index.html` in terminal.
   - On macOS: Run `open index.html`
   - On Linux: Run `xdg-open index.html`
